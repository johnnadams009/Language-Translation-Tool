# 🌐 AI Language Translation Tool

An AI-powered translation web application built with **Python**, **Streamlit**, and the **Google Gemini API**. It supports seamless translation across major global languages and 20+ official Indian languages with natural phrasing and contextual accuracy.

---

## 🚀 Live Demo

Check out the live web app here:  
👉 **[Launch Live App](https://language-translation-tool-ccxconhd7osre4f2y7syx2.streamlit.app/)**

---

## ✨ Features

- **Multi-Language Support**: Translates between major global languages (English, Spanish, French, Japanese, Mandarin, etc.) and scheduled Indian languages (Hindi, Tamil, Telugu, Bengali, Marathi, Gujarati, Kannada, Malayalam, Urdu, and more).
- **Auto Language Detection**: Automatically detects the source language input.
- **Context-Aware Translations**: Powered by Google Gemini to maintain tone, grammar, and nuance.
- **Clean Web Interface**: Fast, responsive UI built with Streamlit.

---

## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Framework:** Streamlit
- **LLM / AI Model:** Google Gemini API (`google-genai`)
- **Deployment:** Streamlit Community Cloud
